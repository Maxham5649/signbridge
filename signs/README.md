# โฟลเดอร์คลิปวิดีโอภาษามือไทย

วางไฟล์วิดีโอรวมไฟล์เดียวที่นี่ ชื่อ `1.mp4` (ต้องตรงกับ `SIGN_VIDEO_SRC` ใน `../signVocab.js`):

```
signs/1.mp4
```

แต่ละคำใน `signVocab.js` อ้างอิงไฟล์นี้ไฟล์เดียว ด้วยช่วงเวลา `start`/`end` (วินาที) — ระบบจะ seek ไปเล่นเฉพาะช่วงนั้นตอนตรวจพบคำที่ตรงกันจากเสียงพูด

## ⚠️ คลิปไม่ได้อยู่ใน git — อยู่ที่ GitHub Release

`signs/*.mp4` อยู่ใน `.gitignore` โดยตั้งใจ เพราะไฟล์ที่ commit เข้า git history แล้ว
**เอาออกให้หมดจริงไม่ได้** — blob ยังเข้าถึงได้ผ่าน commit SHA เก่าแม้ rewrite history
และ force push ไปแล้ว (ต้องติดต่อ GitHub Support ให้ล้างให้) ส่วน Release asset ลบเองได้

เว็บที่ deploy แล้วจึงโหลดคลิปจาก `SIGN_VIDEO_FALLBACK_SRC` ใน `../signVocab.js`
ตอน dev บนเครื่อง ถ้ามี `signs/1.mp4` อยู่ ระบบจะใช้ไฟล์ในเครื่องก่อนเสมอ

### เปลี่ยน / เพิ่มคลิป
1. อัปไฟล์ใหม่เป็น asset ของ Release (ชื่อไฟล์ต้องตรงกับที่อยู่ใน `SIGN_VIDEO_FALLBACK_SRC`)
2. แก้ `start`/`end` ของทุกคำใน `signVocab.js` ให้ตรงกับเวลาจริงในคลิปใหม่
3. commit + push — เว็บและ APK อัปเดตทันที ไม่ต้อง build APK ใหม่

### ลบคลิปออก
ลบ asset ทิ้งจากหน้า Release — เว็บจะโหลดคลิปไม่ขึ้นแล้ว fallback ไปอวาตาร์ + ข้อความอัตโนมัติ

## ข้อกำหนดคลิป
- ควรเป็นคนที่ใช้ภาษามือไทยได้จริง (เช่นคนหูหนวกหรือล่ามภาษามือ) เป็นผู้ทำท่า — ท่าที่ผิดจะสื่อความหมายผิดจริงกับผู้ใช้งาน
- แต่ละท่าสั้น ๆ พอสำหรับ 1 คำ/วลี (ประมาณ 1-3 วินาที) ไม่ต้องมีเสียง
- แนะนำพื้นหลังเรียบ แสงสว่างพอเห็นมือ/นิ้วชัด เพื่อให้ดูง่าย

## เพิ่มคำศัพท์ใหม่
เพิ่มรายการใหม่ใน `signVocab.js` (มี `id`, `match`, `start`, `end`, `label`) ระบุช่วงเวลาที่คำนั้นอยู่ในไฟล์ `1.mp4` — ระบบจะจับคู่คำที่ถอดเสียงมาได้อัตโนมัติ (จับคำสะกด/ถอดเสียงเพี้ยนเล็กน้อยได้ด้วย ไม่ต้องตรงเป๊ะ 100%)
