สแกนเพื่อโหลดลงมือถือ

เปิดกล้องมือถือส่องที่ QR — จะเด้งมาหน้านี้ แล้วกดปุ่มดาวน์โหลดด้านบน

วิธีติดตั้ง

  1. กด ดาวน์โหลด APK ด้านบน รอโหลดจบ
  2. เปิดไฟล์ที่โหลดมา — Android จะเตือนว่า "ไม่อนุญาตให้ติดตั้งจากแหล่งนี้"
  3. กด ตั้งค่า → เปิดสวิตช์ "อนุญาตจากแหล่งที่มานี้" → กดย้อนกลับ
  4. กด ติดตั้ง รอสักครู่ เสร็จแล้วเปิดใช้ได้เลย
ต้องมี Chrome ในเครื่อง — แอพนี้ใช้เอนจินของ Chrome ในการฟังเสียงและทำวิดีโอคอล ถ้าไม่มี ระบบถอดเสียงพูดจะไม่ทำงาน

ต้องใช้อะไรบ้าง

  1. สองเครื่อง — เป็นวิดีโอคอลสองฝั่ง ฝั่งผู้หูหนวกกับฝั่งผู้ได้ยิน เปิดชื่อห้องเดียวกันแล้วเลือกบทบาทตรงข้ามกัน
  2. อินเทอร์เน็ต — วิดีโอคอลและระบบถอดเสียงทำงานผ่านเน็ต
  3. สิทธิ์กล้องกับไมค์ — ครั้งแรกที่เข้าห้อง Chrome จะขอ ต้องกดอนุญาต
  4. เสียงภาษาไทย (ถ้าอยากให้อ่านออกเสียง) — ต้องมี Google Text-to-Speech พร้อมชุดเสียงไทย ติดตั้งฟรีจาก Play Store
